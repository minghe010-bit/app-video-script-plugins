# APP功能更新短视频脚本生成器

用于为“私募排排网APP”生成功能更新宣传短视频脚本。

用户只需提供功能名称和功能介绍，插件便会从用户视角提炼痛点、使用场景和功能价值，输出一份可直接交给剪辑人员制作的30–60秒短视频脚本。

## 主要功能

- 提炼功能解决的用户问题
- 将产品描述转化为用户价值
- 设计30–60秒短视频节奏
- 输出画面、字幕、旁白和剪辑说明
- 生成视频标题、封面文案和核心卖点
- 自动适配新增功能、功能升级和效率优化等类型
- 遵循金融内容合规要求

## 输入示例

```text
【功能名称】
基金对比

【功能介绍】
支持同时查看和比较多只基金的关键指标。
```

即使功能介绍比较简单，插件也会先根据已知信息生成合理脚本，不会机械复述原文，也不会虚构未提供的按钮名称、数据字段和操作路径。

## 输出内容

插件默认输出：

1. 30–60秒短视频脚本表格
2. 画面设计
3. 屏幕字幕
4. 旁白或口播
5. 剪辑说明
6. 三个方向的视频标题
7. 封面主标题和副标题
8. 三条核心卖点
9. 必要的待确认事项

## 安装方法

首先，将本仓库添加为 Codex 插件市场：

```powershell
codex plugin marketplace add minghe010-bit/app-video-script-plugins
```

然后安装插件：

```powershell
codex plugin add app-feature-update-video-script-generator@app-video-script-plugins
```

安装完成后，请重启 Codex，并在新任务中使用插件。

## 使用方法

在 Codex 中直接输入功能信息，例如：

```text
请根据以下信息生成APP功能更新短视频脚本。

【功能名称】
基金对比

【功能介绍】
支持同时查看多只基金的关键指标。
```

也可以输入：

```text
把下面这段APP更新说明整理成剪辑师可以直接使用的短视频脚本。
```

## 输出特点

脚本将优先采用以下结构：

```text
用户痛点
→ 功能出现
→ 操作演示
→ 核心亮点
→ 用户价值
→ 自然CTA
```

开头3秒直接呈现用户问题，避免使用“重磅上线”“震撼升级”等夸张表达。

## 金融合规

插件生成内容时遵循以下要求：

- 不承诺投资收益
- 不暗示功能可以提高收益
- 不使用“稳赚”“精准预测”“抄底
